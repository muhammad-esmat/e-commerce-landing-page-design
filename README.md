# Bamboo Store

An e-commerce frontend template built with HTML and CSS, featuring a modern design for a tech hardware shop.

## Overview

**Bamboo Store** is a website template designed for an online tech store. It showcases product categories, hot offers, and top sellers with a clean, teal-themed interface using the Roboto font family.

## Features

- **Responsive Layout**: Flexbox-based design with rounded corners and smooth hover animations.
- **Key Sections**:
  - **Header**: Navigation with login button and links.
  - **Hero**: Welcome message, search bar, and banner image.
  - **Hot Offers**: Product cards with discount badges and hover scaling effects.
  - **Top Sellers**: High-demand items with category details.
  - **Categories**: Quick navigation to product types.
  - **Footer**: Copyright and image attribution credits.
- **Visual Effects**: CSS transitions for button hovers and card scaling (`transform: scale(1.25)`).

## Setup

1. **Clone or Download** the repository.
2. Ensure the `images/` folder contains all referenced assets (logos, product photos, discount badges, icons).
3. Open `index.html` in any modern web browser.
